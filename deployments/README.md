# Deployments

`devnet.json` is generated by the deployment scripts and is gitignored:

```sh
make bootstrap   # Directory, Accounts, Oracle, rNGN/rKES zones, Components
make pool        # pool setup + FxPool deploy
make book        # TransferBook deploy + Components lock
```

It records the Directory, AccountFactory, OracleHub, zone and Components URIs plus installation
markers. It contains no private keys; devnet keys live in `.devnet/` (gitignored).
