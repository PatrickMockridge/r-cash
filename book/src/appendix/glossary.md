# Glossary

**Account** — the per-owner contract that holds a `PurseStore`, an `AccountGate` and the
transfer op ledger. One account per owner public key.

**AccountGate** — the component that derives the caller's REV address from `deployerId` and
compares it with the owner. It is how "not owner" is decided.

**Asset** — an ERTP resource identified by an asset id. Native REV is one asset; each local
stablecoin is another.

**AssetResolver** — the component that maps an asset id to its issuer: native REV through the
native issuer, other assets through `CurrencyRegistry`.

**Attestation** — a reply that identifies a template and a currency without returning a
capability or a key. Registries verify it before listing.

**Basis point (bps)** — one hundredth of a percent, `1/10000`. Spreads, MCRs, fees and shares
are expressed in bps.

**Buffer / SurplusBuffer** — the per-currency first-loss absorber. It collects realised
interest as `surplus`, carries bad debt as `sin`, absorbs losses and pays the savings share.

**Capacity / Close factor** — the maximum share of a vault's debt a liquidator may repay in one
action, `ceil(accrued * closeFactorBps / 10000)`.

**Capability** — a Rholang name that authorises an operation. R-Cash keeps mint, burn,
custody, liquidation, settlement, PSM, buffer, savings, directory and market capabilities in
closures; they are never returned or stored.

**Claim secret** — a 32-byte bearer secret generated by the sender. The chain stores only its
hash. Anyone with the secret before expiry can claim.

**CollateralCustody** — the component holding a currency system's REV collateral.

**Corridor** — a directed currency pair, such as NGN→KES, with a market and, off-chain, ramp
partners.

**Currency mesh** — the full mesh of direct FX pairs. The supported set is tracked in
`configs/mesh.json`.

**Deploy** — a signed Rholang transaction. It is atomic; a failure rolls back tuple space and
native REV/ERTP state.

**DeployerId** — the node-provided identity of the deployer. Only `Account` reads it, and only
to compare the public key.

**Deposit facet** — a public, receive-only capability. It is safe to hand to a counterparty as
a payout destination.

**ERTP** — the EverydaR Token Protocol: issuers, purses, payments and amount math. A payment
is consumed exactly once.

**External asset** — a bridged asset listed through an adapter (`kind: external`). It has no
vault, PSM, savings or liquidation and is priced by its own feed.

**Feed** — a per-currency `OracleFeed` with three reporters, a median and freshness/spread/band
checks.

**Finality** — the point at which a block is irreversible. R-Cash reports success only at a
finalized block that does not list the deploy in `rejectedDeploys`.

**FxPool** — the oracle-anchored AMM for one unordered pair. It holds two purses and an LP
token kit.

**Governor** — the 2-of-3 admin authority with per-domain nonces and a 100-block timelock.

**`sin`** — outstanding bad debt net of surplus. While `sin > surplus`, new minting is refused
with `"recapitalise"`.

**Interest** — per-block accrual on vault debt:
`ceil(debt * ratePerBlock * (now - lastHeight) / 1e12)`.

**LP token** — the ERTP token representing a pro-rata claim on a pool's reserves.

**LiquidityLock** — the one-shot lock holding seed liquidity until a configured height.

**ListingViews** — the client-facing projection of currencies and markets.

**MarketIndex** — the component that stages, activates, pauses and delists markets, and
records both orientations of a pair.

**MCR** — minimum collateral ratio, in bps. A 15,000 bps MCR means 150% over-collateralisation.

**Memo** — a bounded plaintext string attached to a transfer. It is public.

**opId** — an idempotency key unique per owner. A completed replay returns the original
transfer; a pending replay returns `(false, "pending", id)`.

**OracleHub** — the stateless cross-rate calculator. It returns a rate and the age of each
feed; the caller enforces its own freshness bound.

**PegStabilityModule (PSM)** — the par issuance/redemption venue against a finite REV reserve,
with a fee on both sides and a signed `stableDebt`.

**Phlo** — the fee unit for a deploy. A claim is a signed deploy and costs phlo.

**Purse** — an ERTP holding of one asset, owned by an account. A `PurseStore` creates one per
asset at first use.

**REV** — the native token of rholo and the collateral asset for every stablecoin.

**Rholang** — the reflective, concurrent language the contracts are written in. Authority is a
name; state is a cell; a deploy is atomic.

**Rholphin** — the name of the Lean formal-specification package under `spec/lean/`. It is not
a separate product.

**Root** — the only singleton directory. It maps stable keys to versioned URIs and can be
frozen.

**SavingsPool** — the per-owner share pool that receives the buffer's savings share. Shares
rise in value without new shares being minted.

**Shard** — the node's chain partition. The devnet uses `/root`; the public testnet uses
`/testnet`.

**Sponsor** — the key that signs a currency, feed or market. A sponsor signature binds the
deployment to a public key.

**Stipend** — optional native REV sent by the sender to the recipient's address so the
recipient can pay claim phlo. It is non-refundable and not a meta-transaction.

**Stablecoin** — the per-currency ERTP issuer and its economic system.

**Surplus** — realised interest held by the buffer, before it is absorbed by `sin` or paid to
savings.

**TLA+** — the specification language used for five bounded concurrency models in `spec/tla/`.

**TransferBook** — the component that creates per-transfer contracts, measures payments and
registers transfers.

**TransferContract** — the per-transfer escrow holding the payment and metadata. Claim and
refund race on its cell; exactly one wins.

**Vault** — a record of collateral, debt and last height, owned by an account and operated
through a one-shot capability.

**VaultBook** — the component that owns vault state and the mint/repay/liquidate transitions.
